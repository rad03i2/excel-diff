# Contributing / المساهمة

Contributions are welcome. Keep changes focused, add tests for behavior changes, and run `pytest -q` before opening a pull request. Do not commit real confidential spreadsheets; create synthetic fixtures instead. Please explain user-visible changes in the PR description.

المساهمات مرحب بها. اجعل التغييرات محددة، وأضف اختبارات عند تغيير السلوك، وشغّل `pytest -q` قبل فتح طلب الدمج. لا ترفع جداول حقيقية تحتوي بيانات سرية؛ استخدم بيانات اختبار مصطنعة.

By contributing, you agree that your contribution is licensed under the repository's MIT License.
