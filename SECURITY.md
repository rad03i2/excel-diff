# Security / الأمان

Excel Diff is an offline comparison tool. It makes no network requests and does not upload spreadsheet contents. Treat compared workbooks and generated reports as sensitive because reports can contain cell values.

For vulnerability reports, use GitHub's private security reporting feature when available. Do not publish confidential sample documents in public issues.

أداة Excel Diff تعمل محليًا ولا ترسل محتوى الجداول إلى الشبكة. تعامل مع ملفات الإدخال والتقارير الناتجة كبيانات حساسة لأن التقرير قد يحتوي قيم الخلايا. لا تنشر مستندات سرية في القضايا العامة.
